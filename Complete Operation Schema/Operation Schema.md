Task 2: Complete Operation Schema
Smart Museum Artifact Conservation System
ID	     Pre Condition	                                                                 Events / Input	                                                                                Post Condition
OP01	Chamber has just been powered on; no self-check completed yet.	               Power-on signal; sensor and control-device status responses.	                                   All essential sensors/devices confirmed working (self-check passed), or failure reported and chamber stays out of normal mode.
OP02	Self-check has passed successfully.                            	               Self-check success result.	                                                                   Chamber is in MONITORING mode.
OP03	Chamber is in MONITORING mode; an artifact has been placed inside.         	   Artifact placed; artifact ID and details entered/read.	                                       Artifact identification information is recorded in the system.
OP04	Artifact is registered in the system.	                                       Artifact ID; required temperature and humidity limits.	                                       Artifact's environmental profile is loaded and available for comparison.
OP05	Self-check passed; chamber is powered.	                                       Periodic readings from temperature, humidity, light, vibration, door, artifact-condition and power sensors.Latest sensor values are available to the system; monitoring continues.
OP06	Chamber is in MONITORING mode with an artifact present.	                       Door status sensor reading (open/closed).	                                                   Door state is known; if open, conservation is not started and monitoring continues.
OP07	Door is closed AND artifact profile is loaded.	                               Door-closed signal and profile-loaded confirmation.	                                           Chamber is in CONSERVATION_ACTIVE mode.
OP08	Chamber is in CONSERVATION_ACTIVE mode.	                                       Current temperature and humidity readings; artifact's permitted ranges.	                       Each reading classified as within range or out of range; deviation flagged if out of range.
OP09	Temperature is outside the permitted range; recovery period not expired.	   Temperature out-of-range flag.	                                                               Temperature correction command issued; recovery timer running; artifact NOT yet declared safe.
OP10	Humidity is outside the permitted range; recovery period not expired.	       Humidity out-of-range flag.	                                                                   Humidity correction command issued; recovery timer running; artifact NOT yet declared safe.
